# 霓虹迷宮：核心戰爭

完整的 3D 第一人稱科幻射擊：六個戰役關卡、首領戰、無盡生存，以及武器商店與升級。可在電腦或手機瀏覽器遊玩。

**線上遊玩：** https://alan1234561111.github.io/Game/

## 怎麼玩

載入完成後，在主選單選擇難度，再按「開始戰役」、進入「關卡選擇」，或挑戰「無盡生存」。打倒敵人可取得信用點，到武器商店解鎖武器與強化。

**電腦**

- 點擊畫面以鎖定滑鼠
- `W` `A` `S` `D` 移動，滑鼠轉向
- 滑鼠左鍵射擊，右鍵瞄準
- `Shift` 衝刺，`Space` 跳躍，`C` 或 `Ctrl` 蹲下
- `Q` 或 `F` 閃避衝刺，`R` 換彈
- `E` 或滾輪換槍，`1`–`6` 直接切換武器
- `Esc` 或 `P` 暫停

**手機**

- 左側虛擬搖桿移動，右側滑動轉向
- 螢幕按鈕：射擊、瞄準、跳躍、換彈；點一下衝刺，長按蹲下

## 本機開發

```bash
npm ci
npm run dev          # http://127.0.0.1:5173
npm run build        # 輸出到 dist/
npm run build:pages  # 輸出到 docs/，供 GitHub Pages 使用
```

`vite.config.js` 的 `base` 為 `./`，建置後的靜態檔可放在 `/Game/` 這類子路徑下。
